# TAMO Official Website Starter

A responsive static website starter for TAMO with:
- Home / product overview
- Privacy Policy draft
- Terms of Service draft
- Support page
- Account deletion information page
- Black, orange and gold TAMO styling

## Important before publishing
The legal pages are templates with explicit placeholders. They are NOT final legal documents. Complete them to match the actual production app, its data collection, SDKs, backend, retention, user rights, target countries and publisher details. Obtain appropriate legal review. The account deletion page is informational only until connected to a verified backend deletion workflow.

## Deploy
This is a static site. It can be deployed to Cloudflare Pages. Put the folder contents in a Git repository, connect it in Cloudflare Pages, and set the output directory to `/` (or the repository root if the files are at the root). Cloudflare Pages supports static HTML. A `*.pages.dev` URL is provided; a purchased custom domain can be connected later.

Suggested URLs after deployment:
- https://YOUR-SITE.pages.dev/
- https://YOUR-SITE.pages.dev/privacy.html
- https://YOUR-SITE.pages.dev/terms.html
- https://YOUR-SITE.pages.dev/support.html
- https://YOUR-SITE.pages.dev/delete-account.html

Do not submit placeholder legal pages to app stores.
